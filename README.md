# Prompt Manager

Python 콘솔에서 다양한 프롬프트를 등록하고 관리할 수 있는 프로그램입니다.

프롬프트를 추가하고 목록, 카테고리별 조회, 검색, 상세 보기, 즐겨찾기 등의 기능을 사용할 수 있습니다.

## 개발 환경

- Python 3.10 이상
- Visual Studio Code
- Git
- GitHub

## 주요 기능

1. 프롬프트 추가
2. 프롬프트 목록 보기
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가 및 해제
7. 즐겨찾기 목록 보기
0. 프로그램 종료


## 프롬프트 카테고리

프로그램에서는 다음과 같은 카테고리를 사용할 수 있습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 데이터 저장 방식

프롬프트 데이터는 Python의 리스트와 딕셔너리를 사용하여
프로그램 실행 중 메모리에 저장됩니다.

프로그램을 종료하면 추가하거나 변경한 데이터는 초기화됩니다.

## 실행 방법

프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python prompt_manager.py
